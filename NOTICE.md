# Third-party software

The MIT license at the repository root applies to Mefagram's original code. Dependencies retain their own copyright and license terms; inspect the pinned packages and their license files before redistributing them.

The project uses React Flow, Next.js, React, PGlite, the Model Context Protocol SDK, mcp-handler, ELK, Zod, Lucide, Manrope and Newsreader, among other dependencies. ELK's browser worker and its license are copied from the installed `elkjs` package during `npm ci` into `public/elk-worker.min.js` and `public/elk-license.txt`. They are not committed to the repository but are included in the published npm package, together with ELK's license. Font packages include their own font licenses. No paid React Flow Pro feature or model API service is required.

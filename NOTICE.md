# Third-party software

The MIT license at the repository root applies to Mefagram's original code. Dependencies retain their own copyright and license terms; inspect the pinned packages and their license files before redistributing them.

The project uses React Flow, Next.js, React, Better Auth, PGlite, Drizzle, the Model Context Protocol SDK, ELK, Lucide, Manrope and Newsreader, among other dependencies. ELK's browser worker and its license are copied from the installed `elkjs` package during `npm ci` into `public/elk-worker.min.js` and `public/elk-license.txt`. Those generated files are not committed. Font packages include their own font licenses. No paid React Flow Pro feature or model API service is required.
